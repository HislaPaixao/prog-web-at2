# Cafofo do Peludos
A ONG resgata, cuida e conecta animais a novas familias com foco em adocao responsavel, acolhimento e voluntariado.

# Inicialização do Projeto 
- Na pasta raiz do projeto(cd cafofo-dos-peludos), abra o terminal e escreva 'npm install'
- Apos a instalação escreva npm start e dê enter
- Copie https que vai aparecer no terminal e cole no navegador
